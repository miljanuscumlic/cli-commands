## Supported Software

The cli for the programms below is partially covered with this repository:
| Command | Program Name | Description | Website |
| :------ | :------------- | :------------ | :------ |
| `bash` | Bash | Bash (short for "Bourne Again SHell") is an interactive command interpreter and scripting language. | [link](https://www.gnu.org/software/bash/) |
| `docker` | Docker | Docker is a set of products that uses operating-system-level virtualization to deliver software in packages called containers. | [link](https://www.docker.com/) |
| `gh` | GitHub Cli | Command line interface tool that enables interaction with the GitHub directly from the terminal | [link](https://cli.github.com/) |
| `git` | Git | Git is a distributed version control software system that is used for control of source code or data. | [link](https://git-scm.com/) |
| `glab` | GitLab Cli | Command line interface tool that enables interaction with the GitLab directly from the terminal | [link](https://docs.gitlab.com/cli/) |
| `go` | Go | Go is a high-level, general-purpose programming language that is statically-typed and compiled. | [link](https://go.dev/) |
| `mvn` | Apache Maven | Maven is Build automation tool used primarily for Java programming language projects. | [link](https://maven.apache.org/) | 
| `vim` | Vim | Vim (short for "vi improved") is a free and open-source text editor. | [link](https://www.vim.org/) |
